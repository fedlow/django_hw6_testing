# Галерея сотрудников (Django ORM & Testing)

Веб-приложение на Django для управления карточками сотрудников, их фотографиями и контроля рассадки за рабочими столами. Проект демонстрирует продвинутую работу с базой данных через Django ORM и покрыт юнит-тестами.

## 📋 Описание проекта

Приложение позволяет вести базу сотрудников, отслеживать их стаж, должности и рабочие места. Реализована строгая валидация рассадки: тестировщики и разработчики не могут сидеть за соседними столами.

**Основные возможности:**
*   **Управление данными:** Модель сотрудника включает ФИО, пол, навыки, дату приема на работу, должность и номер стола. Поддерживается загрузка галереи фотографий с сортировкой.
*   **Валидация:** При добавлении сотрудника срабатывает проверка, запрещающая сажать QA-инженеров рядом (за соседние столы) с разработчиками.
*   **Главная страница:** Отображает общее количество сотрудников и карточки 4-х последних принятых на работу.
*   **Список сотрудников:** Выводит всех сотрудников с пагинацией (по 10 человек). Карточки содержат первое фото, ФИО, навыки и стаж в днях.
*   **Подробная карточка:** Доступна только авторизованным пользователям. Содержит заглавное фото, полную информацию, стаж, номер стола и галерею с остальными фотографиями.
*   **Оптимизация:** Запросы к базе данных оптимизированы с использованием `prefetch_related` и `select_related`.
*   **Тестирование:** Проект покрыт тестами (доступность страниц, контекст, права доступа, валидаторы).

## 🛠️ Стек технологий

## 🚀 Инструкция по локальному запуску

1. **Клонируйте репозиторий:**
   git clone https://github.com/fedlow/django_hw5_testing.git
   
   cd django_hw5_testing
Создайте и активируйте виртуальное окружение:

bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
#### Для macOS/Linux:
source venv/bin/activate

### Установите зависимости из файла requirements.txt:

pip install -r requirements.txt

### Примените миграции для создания базы данных:

python manage.py migrate

### Создайте суперпользователя (для доступа в админку):

python manage.py createsuperuser

### Запустите сервер разработки:

python manage.py runserver

### Откройте в браузере:

Главная страница: http://127.0.0.1:8000/

Список сотрудников: http://127.0.0.1:8000/employees/

Панель администратора: http://127.0.0.1:8000/admin/

### 🧪 Запуск тестов

Чтобы убедиться, что всё работает корректно, запустите тесты:

python manage.py test
