# Employee API (Django REST Framework)

REST API для управления сотрудниками, разработанный на Django и Django REST Framework (DRF). Проект включает в себя JWT-авторизацию, ролевую модель доступа и фильтрацию данных.

## 🚀 Основные возможности API

*   **CRUD операции:** Создание, чтение, обновление и удаление сотрудников.
*   **Пагинация:** Вывод списка сотрудников по 10 записей на страницу.
*   **Фильтрация:** Поиск сотрудников по навыкам (`?skills=Python`) и минимальному стажу в днях (`?min_tenure=365`).
*   **JWT Авторизация:** Безопасная аутентификация с использованием Access и Refresh токенов.
*   **Ролевая модель (Права доступа):**
    *   👁️ **Посетитель** (неавторизованный или обычный юзер): Может только просматривать список и детали сотрудников (GET).
    *   🔧 **Смотритель** (группа `Caretaker`): Может просматривать и изменять данные (например, пересаживать за другой стол), но не может создавать или удалять сотрудников.
    *   👑 **Администратор** (`is_staff` или группа `Administrator`): Имеет полный доступ ко всем операциям.
*   **Валидация:** Запрет на рассадку тестировщиков и разработчиков за соседними столами (из предыдущего ДЗ).
*   **Оптимизация:** Использование `prefetch_related` для минимизации запросов к БД.

## 🛠️ Стек технологий
*   Python 3
*   Django
*   Django REST Framework (DRF)
*   Djangorestframework-simplejwt (JWT)

## 🚀 Инструкция по локальному запуску

1. **Клонируйте репозиторий:**
   git clone https://github.com/fedlow/django_hw6_testing.git
   
   cd django_hw6_testing
Создайте и активируйте виртуальное окружение:

bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
#### Для macOS/Linux:
source venv/bin/activate

### Установите зависимости из файла requirements.txt:

pip install -r requirements.txt

### Примените миграции для создания базы данных:

python manage.py migrate

### Создайте суперпользователя (для доступа в админку):

python manage.py createsuperuser

### Запустите сервер разработки:

python manage.py runserver

### Откройте в браузере:

Главная страница: http://127.0.0.1:8000/

Список сотрудников: http://127.0.0.1:8000/employees/

Панель администратора: http://127.0.0.1:8000/admin/

### 🧪 Запуск тестов

Чтобы убедиться, что всё работает корректно, запустите тесты:

python manage.py test

## 📡 Документация API (Эндпоинты)

POST /api/token/ — Получение JWT токена (в теле запроса username и password).

POST /api/token/refresh/ — Обновление JWT токена.

GET /api/employees/ — Список сотрудников (пагинация по 10).

GET /api/employees/?skills=Python&min_tenure=100 — Фильтрация.

POST /api/employees/ — Добавление (Только Админ).

GET /api/employees/{id}/ — Детали сотрудника.

PATCH /api/employees/{id}/ — Изменение (Админ, Смотритель).

DELETE /api/employees/{id}/ — Удаление (Только Админ).
